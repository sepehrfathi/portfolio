PlateYab

Computer vision

An on-premise smart car-finder for parking lots that reads Iranian license plates from existing cameras and shows a visitor exactly where their car is — with a photo — in seconds, running entirely on one mini-PC inside the building (a real ALPR kiosk with a LAN admin panel).

  • Multi-frame evidence fusion lifts accuracy from 79.4% (single frame) to a measured 98.3% per car — the core innovation.
  • 99.08% character-classifier accuracy on 8,383 held-out real samples; a segmentation-free CRNN+CTC reader handles the whole plate at once.
  • Human-in-the-loop active learning fine-tunes the model on-site, from the parking lot's own footage.
  • Fully offline and localized: Jalali calendar, Persian RTL PDF, argon2/CSRF/RBAC security.

Specialism

Prompt & AI Systems Engineering

I treat prompt engineering as the design of the interaction layer between models, data and software—not as writing a clever instruction. That layer must make model behaviour measurable, controllable and maintainable before AI can become a dependable part of a real product.

01

Instruction & context architecture

I define the model's role, objective, constraints, examples and source priorities explicitly, then supply only the context relevant to the task.

02

Structured outputs

Structured Outputs and JSON Schema turn model responses into reliable software contracts, backed by validation, retries and explicit fallback paths.

03

Tools & agentic workflows

Tool and function calls use least privilege, auditable traces and confirmation for sensitive actions; the model coordinates while deterministic code enforces rules.

04

Grounded knowledge

RAG, targeted retrieval, citations and freshness checks connect answers to verifiable evidence and make missing information explicit.

05

Evaluation & versioning

Prompts, models and settings are versioned like code. Golden datasets, edge cases and regression tests measure quality, latency and cost before release.

06

Safety & resilience

I design defences against prompt injection, data leakage and out-of-scope use, with human review and safe stopping points for consequential decisions.

The goal is not one impressive answer; it is stable, measurable and responsible behaviour at production scale.
