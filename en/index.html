PlateYab

Computer vision

An on-premise smart car-finder for parking lots that reads Iranian license plates from existing cameras and shows a visitor exactly where their car is — with a photo — in seconds, running entirely on one mini-PC inside the building (a real ALPR kiosk with a LAN admin panel).

  • Multi-frame evidence fusion lifts accuracy from 79.4% (single frame) to a measured 98.3% per car — the core innovation.
  • 99.08% character-classifier accuracy on 8,383 held-out real samples; a segmentation-free CRNN+CTC reader handles the whole plate at once.
  • Human-in-the-loop active learning fine-tunes the model on-site, from the parking lot's own footage.
  • Fully offline and localized: Jalali calendar, Persian RTL PDF, argon2/CSRF/RBAC security.

CAR-T Target Discovery

Bioinformatics · Oncology

A full-stack system that identifies and ranks candidate target antigens for CAR-T cell-therapy design from real NCBI GEO genomic data — a rigorous, hypothesis-generating research tool with an AI interpretation layer.

  • Five-stage pipeline: data acquisition (NCBI GEO) → differential expression → surface-antigen filter (UniProt, GO terms) → scoring → visualization.
  • Validated by rediscovering clinically-approved targets: CD19 in ALL (rank 1), CD33 & FLT3 in AML, HER2/MUC1/EpCAM in breast cancer.
  • FastAPI pipeline + a React/Recharts dashboard; the AI layer enforces scientific caution and makes no clinical claim.

Signature skill

Prompt Engineering

I engineer language and vision models into production systems where correctness, safety and reproducibility matter — not chatbots, but AI components with strict contracts, tested like any other critical code.

01

Strict-schema contracts

Every model response is JSON-validated and clamped to enums and ranges in code. Stray keys and out-of-range values are discarded before they reach a user — the model proposes, the schema disposes.

02

Separation of duties

The model perceives or narrates; deterministic code decides. In my Norwegian risk platform, AI vision describes the roof, but explicit code sets the score — the model never makes the clinical or financial call.

03

Determinism & reproducibility

Temperature 0 for perception and classification, low temperature for narrative, content-hash caching. Same inputs, same output — a prerequisite for anything auditable.

04

Anti-hallucination guards

Unknown means null and lower confidence, never a fabricated guess. Un-assessed states are shown explicitly, and caution is enforced by the prompt itself.

05

Systematic reasoning methods

Structured prompt methods — quadrant-by-quadrant counting, count-once-across-images, evidence weighting — that make a model measurably, repeatably more reliable on hard real-world inputs.

06

On-device AI

Integrating language and vision models locally, under tight constraints, so intelligent systems keep working where cloud AI can't.

These aren't abstractions — every principle here is load-bearing in a system I've shipped.
