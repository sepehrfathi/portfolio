# ابزار نگهداری سایت سپهر فتحی

نسخهٔ نهایی هر هفت زبان مستقیماً در پوشه‌های `fa`، `en`، `ar`، `zh`، `ru`، `es` و
`no` نگهداری می‌شود. برای اعمال دوبارهٔ تنظیمات مشترک سایت، بخش حرفه‌ای مهندسی
پرامپت، دامنه و تصویر پروفایل اجرا کن:

```bash
python3 _src/build.py
```

فایل `finalize_sep.py` این تغییرها را روی تمام زبان‌ها یکسان نگه می‌دارد.
کد تولیدکنندهٔ قدیمی داخل `build.py` فقط برای مرجع حفظ شده و دیگر محتوای قبلی را
روی صفحات شخصی‌سازی‌شده بازنویسی نمی‌کند.

پوشهٔ `_src` ابزار توسعه است و لازم نیست روی هاست آپلود شود.
